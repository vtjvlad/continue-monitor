# Continue Monitor

Веб-панель для управления Continue CLI на Ubuntu.

## Стек

- Node.js ES Modules
- Express
- HTML, CSS, JavaScript без фронтенд-фреймворков

## Основные требования

- Авторизация по токену
- Запуск заданий Continue CLI
- Выбор рабочей директории
- Просмотр состояния и вывода заданий
- Остановка выполняемых процессов
- Диагностика CLI и ошибок
- Ограничение доступа к рабочим каталогам
- Отдельный systemd-сервис

## Предварительные условия

- Ubuntu 24.04+
- Node.js 22+
- Continue CLI (`cn`)
- Настроенная авторизация Continue
